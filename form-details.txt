PROJECT DETAILS FOR GOOGLE FORM

Project Name:
   AI Student Notes Summarizer & Quiz Generator

Project Description:
   An AI-powered web application designed for students to instantly summarize lengthy study materials, lecture notes, and textbook content into clear, actionable bullet points, while automatically generating quick practice quizzes to test comprehension.

Project Statement:
   Students often face information overload with massive syllabi and lengthy notes, making rapid revision difficult during exams. Traditional note-taking and manual flashcard creation are time-consuming, leading to inefficient learning.

Your Solution:
   Our solution leverages Gemini AI to parse study notes and extract core key concepts into easy-to-read bullet points. It also dynamically generates a 4-question multiple-choice quiz so students can immediately test their understanding.

Uniqueness & Innovation:
   Unlike basic summarizers, this tool combines AI-powered summarization with automated 4-question quiz generation in a simple single-page browser interface. It also includes a mock mode for testing the workflow without an API key.

Technology Stack:
   HTML5, Tailwind CSS, JavaScript (ES6+), Google Gemini API, localStorage, VS Code, Git & GitHub
